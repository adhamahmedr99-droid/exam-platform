# منصة الامتحانات (النسخة الكاملة بالسيرفر)

منصة امتحانات إلكترونية كاملة للمدرس: امتحانات بأنواع أسئلة مختلفة، أكواد لمرة واحدة بتتتحقق على السيرفر، تايمر بتسليم تلقائي، حفظ إجابات لحظي على السيرفر، تصحيح تلقائي + مقالي يدوي، تحليلات، وتقارير أولياء أمور.

## المعمارية

- **الواجهة**: `index.html` ملف واحد (SPA بدون build step) على GitHub Pages.
- **الباك إند**: Supabase (PostgreSQL + Auth + Row Level Security + RPC functions).
- **قاعدة البيانات**: `schema.sql` — الجداول + السياسات + دوال:
  - `redeem_code(token)`: تحقق سيرفر من الكود (لمرة واحدة، فترة الإتاحة، النشر)، فتح/استئناف جلسة، وإرجاع الأسئلة **بدون الإجابات الصحيحة**.
  - `save_answer(...)`: حفظ لحظي للإجابات (الطالب يكمل من أي جهاز).
  - `submit_exam(...)`: تصحيح موضوعي على السيرفر، منع التسليم المكرر، إغلاق الكود (`completed`).
  - `exam_code_status(exam)`: حالة كل كود (غير مستخدم / قيد الحل لحظيًا / مكتمل).
- **الصلاحيات**: الطالب المجهول لا يلمس أي جدول مباشرة (RLS) — كل شيء عبر الدوال أعلاه. المدرس يرى ويعدّل بياناته فقط.

## التشغيل

1. انسخ `schema.sql` في SQL Editor بتاع مشروع Supabase وشغّله.
2. حط `SUPABASE_URL` و `SUPABASE_ANON_KEY` في أول `index.html` (من Project Settings → API).
3. فعّل GitHub Pages على الفرع الرئيسي — الموقع يشتغل فورًا.

## اللي محتاج إعداد إضافي (موثّق، البنية جاهزة)

- **إرسال واتساب أوتوماتيك**: يحتاج WhatsApp Business API (مزوّد مثل Twilio أو Meta Cloud API) + Supabase Edge Function. حاليًا الإرسال بضغطة واحدة عبر wa.me.
- **إيميل أوتوماتيك لأولياء الأمور**: Edge Function + مزوّد بريد (Resend/SES).
- **PDF**: زر "طباعة / PDF" بيستخدم طباعة المتصفح (حفظ كـ PDF) — كافي لمعظم الاستخدام.
